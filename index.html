Automation case

How I reduced regression time by ~90% with 500 automated tests

I worked as the only QA in a small product team. A lot of regression was manual, so I started building Playwright automation from scratch — first the key user flows, then API setup, fixtures, test data, CI and less critical scenarios. Over time the suite grew to around 500 automated tests, covered ~95% of key business flows and reduced regression time by around 90%.

AI / LLM testing

AI is an additional part of my QA work, not a replacement for the fundamentals. I test chatbots, agents, RAG systems, tool/API calls, memory and context, multi-turn behavior, hallucinations, retries, guardrails and prompt-injection scenarios. I also use AI tools daily for requirements analysis, test design, automation and debugging.
